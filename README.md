# SWGPush Backups information pages

Static application information, privacy and terms pages for the operator's
Google Drive backup integration. These pages do not execute the backup tool.

Public files: `index.html`, `privacy.html`, `terms.html`, `styles.css`,
`.nojekyll`, and this README. No build dependencies or browser scripts.

Proposed deployment: public repository `Pushindirt/pushindirt.github.io`,
GitHub Pages using branch `main`, folder `/` (root), HTTPS enabled.

Expected URLs after deployment:

- Homepage: `https://pushindirt.github.io/`
- Privacy: `https://pushindirt.github.io/privacy.html`
- Terms: `https://pushindirt.github.io/terms.html`

General project questions: <https://github.com/Pushindirt/pushindirt.github.io/issues>.
The operator's support email is available on the Google consent screen for
private data requests. Do not post credentials or backup contents in issues.

These information pages are maintained separately from the game source and
operational runtime. Backups and OAuth credentials must never be added here.
