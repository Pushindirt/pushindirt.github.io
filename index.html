SWGPush

Backups for a persistent galaxy.

SWGPush Backups is a private administration tool used by the server operator to protect game-server data and check that backup archives can be restored.

What the application does

The tool creates local server-database backups, validates restored copies, and uploads completed archives to the operator’s Google Drive backup folders. It checks the uploaded files before marking an offsite copy complete.

Google authorization is used by the operator to connect the backup tool to their own Drive account. Players do not need to authorize a Google account. This website provides information about the application; it has no sign-in form or backup download service.

How Google Drive access is used

The configured Drive permission allows broad file access. The backup workflow uses the configured backup folders for archive transfers and verification, and checks account storage availability. Credentials and backup archives are stored outside this public website and its repository.

Read the privacy notice for information about authorization, storage, retention and access removal, and the terms of use for the tool’s intended use.

Project contact

Maintained by Pushindirt. General questions can be raised in the information-site repository. For a private data request, use the support email displayed on the application’s Google consent screen.
