Privacy notice

SWGPush Backups is operated for the private administration of SWGPush. It connects the operator’s server-backup workflow to the operator’s Google Drive account.

Access and information used

The operator authorizes access through Google. The tool stores the resulting access and refresh tokens, together with its client configuration, in restricted files on the server. It uses these credentials to make authenticated Google Drive requests.

The Drive permission grants broad access to files in the authorized account. The configured backup jobs use backup-folder and file metadata, account storage information, and backup archive contents to upload and verify server backups. Archives may contain game-world data and account or other server-database records. Players are not asked to authorize Google accounts.

Purpose and sharing

Information is used for server backup, restoration, integrity verification and storage management. This tool does not sell Google user data, use it for advertising, or use it to train AI models.

Google processes the authorized Drive requests and stores uploaded archives. Contabo hosts the server on which local backups and credentials are stored. Access to stored copies is governed by the operator’s server and Google Drive permissions. The backup workflow does not publish archives or credentials on this website.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

Local backup copies are retained according to the configured backup policy. Offsite archives remain in Google Drive until the operator removes them; the current offsite workflow does not automatically prune them. Private credential snapshots may remain on the server until the operator removes them.

Credentials are retained while the integration is in use or until removed by the operator. They are not committed to this public information-site repository.

Removing access or data

The operator can revoke this application’s access through Google Account connections and remove the stored server credentials. Revocation stops further authorized access but does not delete archives already stored locally or in Google Drive. Stored copies must be removed separately by the operator, subject to the storage provider’s deletion and recovery behavior.

For a private access or deletion request, contact the support email displayed on the application’s Google consent screen. General questions can be raised in the information-site repository; do not include credentials or private backup contents in public issues.

This information website

These pages contain no forms, application cookies, analytics scripts or advertising. GitHub Pages hosts the website and records visitor IP addresses for security purposes under the GitHub Privacy Statement. This website does not run the backup tool or handle its Google authorization callback.

Changes

This notice will be updated when the application’s data practices change. The date above identifies the latest revision.
